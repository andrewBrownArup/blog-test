# Andrew's notebook - test blog

A public, sample-only static blog hosted by GitHub Pages.

**Website:** https://andrewbrownarup.github.io/blog-test/

## Editing

Edit [index.html](index.html) and commit to the repository's default branch.
GitHub Pages publishes the repository root automatically. Deployment progress is
visible in the repository's **Actions** tab and **Settings > Pages**.

The page contains its own CSS and favicon. There are no package dependencies,
JavaScript, databases, forms, or application analytics. Open `index.html` in a
browser to preview it locally. `.nojekyll` disables Jekyll processing.

All posts are demonstration content. The site and source repository are public;
do not add confidential material. This is not an official Arup website.

To stop hosting the site, use **Settings > Pages > Unpublish site**.
